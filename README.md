# HR Analytics and Prediction Model

This project uses machine learning techniques to analyze HR data and predict outcomes such as employee attrition. It includes a web-based dashboard built using Streamlit.

## Project Structure

- `data/` - Contains the dataset used for training and prediction.
- `models/` - Pre-trained machine learning models.
- `notebook/` - Jupyter notebook for data analysis and model development.
- `app/` - Streamlit web application for interaction.

## How to Run

1. Install required libraries: `pip install -r requirements.txt`
2. Run the web app: `streamlit run app/webapp.py`
